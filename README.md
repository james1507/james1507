01 / About
I'm An Nguyen (James), a software engineer with 4+ years of experience building mobile applications, including banking and financial products. I enjoy turning complex requirements into reliable software — from responsive Flutter interfaces to transaction-safe backend APIs.

I care about more than features that work on the happy path: correctness under concurrency, clear error handling, performance, testability, and reproducible debugging.
Engineering mindset: Design for failure, verify behavior with tests, and make important decisions easy to inspect.

04 / What I optimize for
- Correctness: Money-like operations need atomic writes, consistent state, safe retries, and careful access control.
- Reliability: Failure cases should be intentional, observable, and covered by reproducible tests.
- Maintainability: Clear boundaries, focused modules, and documentation should make systems easier to understand and extend.
